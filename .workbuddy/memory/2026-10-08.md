# 2026-10-08 · astrbot-plugin-miyoho

## 新增面板一级分类「群订阅」（订阅的群 + 群员绑定账号）

用户反馈：群里发「订阅米哈游服务」后，面板上根本看不到谁订阅了。

**查到真因（重要）**：`data/zzz/subscribe.json` 被清空成 `{"services": {}}`。
日志证据：13:54:13 群订阅**成功**（`已订阅米哈游服务 ✅`），23:26:41 面板保存社交配置时
`api_social_save` 走了 `subscribe.apply_snapshot(payload["subs"])` —— 前端整份写回，
标签页开得早、状态里 subs 是空的 → 把订阅整份抹掉。social.json 与 subscribe.json 的
mtime 完全一致（23:26:41）就是这一刀的证据。

**做法**：
- 摘掉「社交命令配置 → 保存」里的 subs 分支（`apply_snapshot` 保留但不再挂载，已写注释警告）。
- 订阅改成**服务端为准、逐条改**：新增 `miyoho/social/subscribe_routes.py`
  （overview / group.enabled / group.drop / member.enabled / member.drop / member.restore），
  每个写操作都回整份最新总览，前端直接覆盖状态。
- `seen.py` 升级 v2：连群名 + 群员昵称一起记（兼容 v1 老文件）。QQ 官方常常给不出昵称，
  只在非空时覆盖。
- 新增 `miyoho/social/member_binds.py`：群员绑定行的启用/删除状态
  （行是 seen × bind 算出来的，只有「态度」落盘）。
- 面板：新增一级分类「群订阅」（js/frag/subscribe.js + css/frag/subscribe.css，gs-* 前缀），
  两个子页签「订阅的群」「群员绑定」；把「QQ机器人配置」里那块订阅开关摘掉换成指路。
- 顺手加了群员门槛：`member_binds.allowed` 全部记录被禁用时 dispatch 静默不放行。

**改了 14 个文件**（工作区 → 已同步到线上插件目录）。
