# astrbot-plugin-miyoho

米哈游（米游社）插件 · AstrBot 版。由 malu_qq_bot 的 miyoushe 插件完整移植：账号扫码登录、绝区零全线查询、QQ 社交命令、设备指纹配置，一个不缺。

## 功能

- **米游社账号**：扫码登录（HYP 一次拿全 stoken + cookie_token）/ 多账号切换 / 删除，凭证 Fernet 加密落盘
- **绝区零查询**：抽卡记录（增量/全量同步 + 汇总）、危局、防卫战、深境、角色查询、角色详情、体力、伏特、档案、月度、图鉴、签到、自动签到
- **社交命令**：可配置的 QQ 群命令（查角色 / 查体力等），按实例与群范围分发
- **设备指纹**：配置设备参数解开角色列表 10041 风控

## 使用

- WebUI → 插件详情 → 打开「panel」页面（账号管理 + 全部查询 + 各项配置都在面板里）
- QQ 命令在面板「社交命令配置」里按需开启

## 依赖

httpx / segno / cryptography / Pillow（`requirements.txt`）

## 数据

凭证与配置落在插件目录 `data/` 下（`.auth_key` 为加密密钥，**丢失只能重新扫码登录**）。
